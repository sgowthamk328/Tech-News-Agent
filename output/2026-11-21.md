## Startup sues Apple in India over tap-to-share contacts feature

**Category:** Policy / Security  |  **Found via:** TechCrunch

U.S.-based startup GG Technologies has escalated its legal dispute against Apple by filing a 781-page patent infringement lawsuit in the Bombay High Court in India. The lawsuit alleges that Apple's native NameDrop feature—introduced in iOS 17 and watchOS 10.1 to let users share contact details by bringing devices close together—violates GG Technologies' Indian patent for proximity-based contact exchange technology. The startup is seeking roughly $162 million (₹15 billion) in damages and an injunction to halt imports and sales of preloaded iPhones and Apple Watches in India.

This legal dispute reflects a broader international struggle over intellectual property surrounding seamless device-to-device data sharing. GG Technologies previously filed a similar suit in the U.S. in April, leading the International Trade Commission (ITC) to open an investigation into potential import restrictions on Apple products. The Indian lawsuit proceeded after mandatory pre-institution commercial mediation between the two parties failed.

For consumers and the market in India, this litigation creates uncertainty around hardware availability and device feature functionality. India is a key strategic growth market and manufacturing hub for Apple, meaning any potential import restrictions or judicial injunctions could severely disrupt local retail expansions and supply chain operations. While the case has not yet been listed for a formal hearing, Apple now faces parallel regulatory and judicial challenges across both American and Indian jurisdictions.

Who's involved: Apple, GG Technologies (creators of StayTouch), founder Gaurav Goel, and the Bombay High Court.

## Amazon's split personality: AWS embraces bot commerce while main site enforces bans

**Category:** Industry News  |  **Found via:** The Register

Amazon is navigating a strategic dichotomy regarding automated AI purchasing. While Amazon's consumer e-commerce site actively blocks AI shopping bots from scraping products and has sued AI browser providers to protect its consumer platform, Amazon Web Services (AWS) is taking the opposite path. AWS Marketplace has launched expanded capabilities designed specifically to enable AI agents to browse, select, and buy cloud software, data feeds, and APIs on behalf of users.

To facilitate these automated business transactions, AWS has integrated the x402 agentic payment protocol—an open standard hosted by the Linux Foundation that enables machine-to-machine payments. Software sellers register with AWS Marketplace and implement the x402 software development kit (SDK), allowing AI agents powered by frameworks like Amazon Bedrock AgentCore to complete purchases automatically. Transactions settle in U.S. dollars through existing enterprise AWS billing accounts, maintaining corporate spending controls while eliminating manual purchasing friction.

This strategy highlights a fundamental split in the tech industry between enterprise operations and consumer retail. On consumer platforms, unauthorized bots disrupt traffic, bypass ads, and complicate fraud detection. In enterprise cloud infrastructure, however, allowing AI agents to procure software, data feeds (such as Reuters or Moody's data via Model Context Protocol servers), and technical services accelerates workflow automation. By adopting standardized protocol rails like x402, AWS aims to establish itself as the underlying infrastructure layer for the emerging machine-to-machine economy.

Who's involved: Amazon Web Services (AWS), AWS Marketplace, Linux Foundation (x402 protocol creators), Coinbase, and Cloudflare.

## PHP 8.6: Things are gonna get a lot more strict around here

**Category:** Technical Release  |  **Found via:** The Register

PHP 8.6 introduces structural security enhancements aimed at removing widespread default configuration vulnerabilities that have historically enabled remote code execution and session hijacking across millions of web applications. In web programming, session identifiers track a user's state after logging in. Historically, PHP allowed insecure session defaults, permitting uninitialized session IDs provided by external callers or exposing session cookies to client-side JavaScript. This architecture made applications vulnerable to cross-site scripting attacks, where malicious scripts steal session cookies, and cross-site request forgery, where external sites trigger unauthorized actions on behalf of authenticated users.

To resolve these structural vulnerabilities, PHP 8.6 enforces strict session security defaults. The engine now rejects uninitialized session IDs, generating fresh, server-validated random IDs instead. Additionally, PHP automatically injects the HttpOnly flag into session cookies by default, preventing JavaScript from accessing sensitive credentials. Cookie transmission is also restricted to same-site interactions and top-level navigation, blocking unauthorized cross-site POST requests. At the core runtime level, PHP 8.6 hardens string handling against null byte attacks (strings containing trailing zero values), which attackers frequently use to bypass C-based function boundary checks. The engine now triggers explicit errors rather than silently processing truncated inputs. Crucially, core file operations and data operations now return explicit failure flags, giving developers clear runtime feedback to prevent data integrity bugs.

Beyond defensive hardening, the release updates PHP's programming capabilities. It introduces Partial Function Application, allowing developers to pre-fill specific function arguments on the fly to generate reusable function bodies. It also integrates a native polling API for asynchronous event-driven networking, a high-precision Duration class for measuring runtime spans over extended periods, and built-in numerical clamping utility functions. Deployment environments must note that pre-existing configuration files will override these default settings unless explicitly updated, meaning administrators must review deployment templates to benefit from the release's default security architecture.

Who's involved: The PHP Foundation, PHP Core Development Team, Jörg Sowa, and backend engineer Rajekevin Dourepoulle.

## Trump FCC declares California isn't allowed to enforce phone service rules

**Category:** Policy / Security  |  **Found via:** Ars Technica

The Federal Communications Commission (FCC) issued a formal order preempting California’s Carrier of Last Resort (COLR) regulations, ordering state regulators to halt enforcement against AT&T. Under traditional state utility framework rules established decades ago, a designated Carrier of Last Resort is legally required to offer basic landline telephone service to any resident or business within its assigned service territory. AT&T sought relief from these obligations to retire its aging legacy copper wire network and cease offering legacy wireline voice services to roughly 184,000 residential and 15,000 commercial customers in California by mid-2027.

This policy change primarily affects California residents and businesses relying on legacy copper landline networks, particularly those in rural or underserved regions where fiber optic infrastructure has not been deployed. While the FCC approved AT&T’s request to substitute legacy landlines with cellular-based wireless voice alternatives, California regulators maintained that AT&T must demonstrate its wireless options meet state standards—such as flat-rate pricing, reliable emergency service, Lifeline subsidies for low-income consumers, and accessibility services for hearing-impaired users. The FCC's decision overrules the state's oversight authority, classifying California's consumer protection rules as an impermissible barrier to federal network modernization efforts.

Looking ahead, this ruling sets up a legal conflict between federal regulators and state authorities. The California Public Utilities Commission (CPUC) had an ongoing proceeding to update its service rules before the target phase-out date of June 1, 2027. Following this preemption order, California officials are expected to challenge the FCC's decision in federal court. This dispute mirrors previous legal battles over state-level telecom oversight, such as net neutrality laws, and could redefine the boundaries between federal authority and state police powers regarding critical utility infrastructure and consumer protections.

Who's involved: Federal Communications Commission (FCC), FCC Chairman Brendan Carr, FCC Commissioner Anna Gomez, AT&T, and the California Public Utilities Commission (CPUC).

## SpaceX's Starshield troubles in Ukraine could threaten its broader military business

**Category:** Policy / Security  |  **Found via:** Ars Technica

Representative Jim Himes, the expected incoming chair of the House Intelligence Committee, sent a formal warning letter to SpaceX founder Elon Musk and a classified communication to the Director of National Intelligence. Himes threatened to block congressional funding for military satellite programs developed by SpaceX. This action stems from an investigation into performance interruptions of Starshield, SpaceX's specialized defense satellite network, in Ukraine. Ukrainian forces reported that satellite connections were dropping at speeds between 130 and 161 kilometers per hour, hampering frontline drone operations and logistics. The central dispute centers on whether SpaceX modified government contract services unilaterally or followed official U.S. government directives.

This policy conflict primarily affects SpaceX, the U.S. Department of Defense, and allied defense operations relying on commercial satellite infrastructure. Congress holds the power of the purse, meaning lawmakers can restrict budget appropriations for major defense projects. Threatening SpaceX's funding impacts high-stakes national security initiatives, such as the Space Force's $2.29 billion Space Data Network Backbone contract for missile defense and National Reconnaissance Office intelligence satellite builds. The situation highlights growing legislative scrutiny over defense dependence on private technology vendors during active geopolitical conflicts.

Next, Congressional Democrats preparing to take leadership in January plan to use their oversight authority to demand classified briefings, review contractual terms, and potentially insert funding restrictions into upcoming defense authorization bills. While the U.S. government remains heavily reliant on SpaceX due to its unique launch and satellite capabilities, lawmakers aim to establish clearer boundaries regarding corporate influence over military operations.

Who's involved: Representative Jim Himes, Elon Musk, SpaceX (Starshield/Starlink), U.S. House Intelligence Committee, U.S. Department of Defense, and Volodymyr Zelenskyy.

## Visa, Mastercard theft included info useful for phishing, but not draining bank accounts, say researchers

**Category:** Policy / Security  |  **Found via:** The Register

Security researchers analyzed leaked sample data from a cyberattack targeting third-party vendors associated with Visa, Mastercard, and JPMorgan Chase. The extortion group behind the attack, known as n0n, published samples representing a fraction of the total stolen data to pressure the victim companies into paying a ransom. Threat intelligence firm SOCRadar parsed the 14 published files containing nearly two million marketing events and confirmed that critical financial details—such as full credit card numbers, expiry dates, CVVs, passwords, dates of birth, and home addresses—were absent from the leak. 

Instead, the stolen records contained mobile phone numbers, Bank Identification Number (BIN) prefixes, email addresses, and specific dates for hotel, airline, and restaurant bookings. While this information cannot be used directly to authorize fraudulent transactions or drain bank accounts, it poses a severe social engineering risk. Attackers can leverage these specific travel schedules and partial banking metadata to craft highly convincing voice-phishing (vishing) or email-phishing campaigns. By impersonating concierge services, hotel representatives, or bank fraud departments, scammers can trick victims into voluntarily handing over sensitive credentials or secondary authentication codes.

Investigators noted that the data format strongly points to a breach at an upstream third-party platform running marketing and concierge reporting services rather than a direct intrusion into the core infrastructure of the credit card giants. Security experts believe the access path aligns with a broader supply-chain campaign exploiting cloud management credentials. Moving forward, financial institutions will monitor for targeted phishing schemes aimed at cardholders, while downstream enterprise customers will continue auditing third-party vendors to identify exposure points across shared cloud storage environments.

Who's involved: Visa, Mastercard, JPMorgan Chase, n0n (extortion group), SOCRadar, and Qubole.

## Experts warn: Nearly everyone in AI is susceptible to a honey-trap scheme right now

**Category:** Industry News  |  **Found via:** TechCrunch

Counterintelligence experts and cybersecurity strategists are warning that the artificial intelligence industry has become a primary target for corporate espionage and foreign intelligence honey-trap operations. Historically, honey traps—where operatives establish manipulative personal relationships to extract sensitive information—were associated with government entities, foreign diplomats, and defense contractors whose personnel undergo rigorous counterintelligence training. However, the rapid concentration of valuable intellectual property within commercial AI firms has shifted nation-state target sets toward technology founders, chip designers, and corporate executives.

Modern honey-trap operations rarely resemble dramatic romantic entanglements; instead, espionage agents frequently pose as prospective venture investors, enterprise clients, recruiters, or strategic consultants. Their goal is to build professional rapport and exploit the human desire for validation and industry connection. Once an unsuspecting target shares non-public roadmaps, export strategies, or internal partner lists, the adversary establishes leverage that can escalate into direct blackmail. 

Generative AI has lowered the operational cost of executing these schemes. Threat actors now use AI tools to generate convincing social media profiles, construct elaborate professional histories, and automate target research, allowing malicious actors to manage multiple covert approaches simultaneously. The intelligence community notes that corporate governance within Silicon Valley often lacks basic counterintelligence protocols. Furthermore, executive exceptionalism—where leadership operates outside standard security oversight—exacerbates corporate vulnerability.

To counter these threats, technology companies are being advised to implement formal counterintelligence training for all staff with access to critical IP. Security experts urge tech firms to dismantle cultures of executive deference, establishing reporting mechanisms where employees feel empowered to flag unusual executive contacts or persistent inquiries regarding confidential technologies.

Who's involved: Nvidia, Jensen Huang, Alice Huang, OpenAI, Aaron Brown (Lumbra), and Perry Carpenter (KnowBe4).
